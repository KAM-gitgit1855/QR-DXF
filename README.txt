QR → DXF レーザー加工アプリ（Android向けPWA）

内容
- index.html: アプリ本体
- manifest.json: ホーム画面追加用の基本設定

使い方
1. index.htmlをHTTPSで公開できる静的ホスティングに置く（例：GitHub Pages）。
2. AndroidのChromeで公開URLを開く。
3. メニューから「ホーム画面に追加」。
4. QR画像を選び、読み取り成功を確認してDXFを生成・保存する。

注意
- QR読み取りライブラリをCDNから読み込むため、初回利用時はインターネット接続が必要です。
- この試作版は、読み取った内容からQRを再生成します。元画像と完全に同じマトリクスではなく、QRデータ内容が同じQRになります。
- 8mmモードはサイズを8mmに固定し、黒モジュールの水平ランをDXFポリラインで出力します。35mmモードは初期サイズ35mm、サイズ変更可、水平蛇行走査です。
- 「以前のDXFと完全に同じ加工経路」を保証するものではありません。実際のレーザーに投入する前にCADで寸法・線幅・加工方向を確認してください。
- 走査ピッチと線幅は別物です。機械のスポット径や材料に合わせてテストしてください。
